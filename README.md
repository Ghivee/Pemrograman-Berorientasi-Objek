# Object-Oriented Programming Coursework

Lab exercises, midterm (UTS) and final exam review (Responsi UAS) files from the Object-Oriented Programming course, written in Java using NetBeans. The weekly sessions build up the core OOP ideas in order: access modifiers and encapsulation, inheritance, polymorphism, composition and aggregation, before the midterm applies them to a small employee-and-product system and the final review ties everything together.

[Baca dalam Bahasa Indonesia di bawah](#bahasa-indonesia)

## Structure

```
Pertemuan 01 .. Pertemuan 09     weekly lab files, one NetBeans project per session
UTS                               midterm exam files: an employee product system
Responsi UAS                      final exam review files
```

Each session folder is its own NetBeans project; open the folder in NetBeans (or import the `.java` files into any IDE) rather than expecting a single top-level project to build everything at once.

## Bahasa Indonesia

Berkas praktikum, UTS, dan Responsi UAS mata kuliah Pemrograman Berorientasi Objek, ditulis dalam Java memakai NetBeans. Pertemuan mingguannya membangun gagasan inti OOP secara berurutan: access modifier dan enkapsulasi, inheritance, polimorfisme, komposisi dan agregasi, sebelum UTS menerapkannya pada sistem produk-karyawan kecil dan responsi UAS merangkai semuanya.

### Struktur

```
Pertemuan 01 .. Pertemuan 09     berkas praktikum tiap pertemuan, satu proyek NetBeans per pertemuan
UTS                               berkas UTS: sistem produk karyawan
Responsi UAS                      berkas responsi UAS
```

Setiap folder pertemuan adalah proyek NetBeans tersendiri; buka foldernya di NetBeans (atau impor berkas `.java`-nya ke IDE apa pun), bukan mengharapkan satu proyek tingkat atas yang membangun semuanya sekaligus.
